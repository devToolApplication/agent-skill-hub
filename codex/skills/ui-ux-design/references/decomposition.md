# UI/UX Evidence Decomposition

Weak workers gather observable facts; the parent designs.

## Existing screen audit

Collect separately:
- routes/screens;
- fields/columns/actions;
- existing states;
- current responsive conditions;
- component primitives/tokens;
- a11y semantics/focus/labels;
- current tests.

## Forms

Collect field types, required/optional rules, validation/error placement, submit/cancel actions, conditional fields, and current mobile grouping. Parent decides grouping/disclosure/layout.

## Tables

Collect row count/data shape, columns, sorting/filtering/pagination, row actions, bulk actions, sticky behavior, current mobile handling. Parent decides table/list/card adaptation.

## Navigation

Collect routes, entry points, hierarchy, current breadcrumbs/tabs/sidebar state. Parent chooses information architecture.

## Design system

Workers may list raw colors, spacing values, typography variants, radius/shadow variants, one-off components and existing equivalent primitives. Parent decides normalization.

## Accessibility

Workers may collect missing labels, focusability, keyboard handlers, semantic elements, ARIA, color-only status, reduced-motion handling. Parent judges user impact and fix direction.
