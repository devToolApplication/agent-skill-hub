# FE Search Focus

For theme tasks locate: provider, token definitions, CSS variables/theme config, theme hook, persistence, SSR initialization, existing semantic token usage.

For responsive tasks locate: breakpoint tokens/hooks/classes/container-query convention and current desktop/mobile render paths.

For accessibility tasks locate: reusable dialog/menu/form/control primitives and current keyboard/focus helpers.
