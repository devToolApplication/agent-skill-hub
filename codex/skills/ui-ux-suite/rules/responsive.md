# Responsive Rules

## Principle

Responsive design may change the interaction pattern.

Do not simply shrink desktop UI.

## Typical Transformations

Desktop table
→ mobile structured list

Desktop sidebar
→ mobile drawer or bottom navigation

Desktop split pane
→ mobile sequential screens

Wide toolbar
→ compact controls + overflow

Hover affordance
→ visible tappable action

## Touch

Do not tightly pack controls.
Make frequent actions comfortably tappable.

## Content Priority

On smaller screens:
- preserve P0/P1
- collapse or defer P2/P3
- avoid hiding essential status
- reduce decorative content before functional content

## Forms

Mobile:
- one column
- native-friendly input types
- avoid side-by-side fields unless very short and strongly related

## Dialogs

Large desktop modal may become:
- full-screen dialog
- dedicated screen
on mobile.

## Testing Widths

Do not design only for named devices.
Test narrow, medium, and wide layouts and stress content with long labels and large values.
