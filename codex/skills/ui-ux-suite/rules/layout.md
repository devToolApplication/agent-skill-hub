# Layout Rules

## Spacing Scale

Preferred:
4, 8, 12, 16, 24, 32, 48, 64

Rule:

distance inside a group
<
distance between groups
<
distance between sections

## Page Hierarchy

Common page order:

Navigation Context
→ Page Title
→ Primary Action
→ Controls
→ Content
→ Secondary information

## Width

Do not stretch text-heavy content across the full viewport.

Use content width appropriate to:
- reading
- forms
- dense data
- dashboards

## Alignment

Use a limited alignment grid.
Avoid arbitrary offsets.

## Sections

Prefer:

Section title
Optional description
Content
Spacing/divider

Do not wrap every section in a card by default.

## Detail Screens

Prefer label/value presentation for read-only details instead of disabled-looking form controls.

## Sticky Regions

Use sticky UI only when it preserves meaningful context:
- table header
- important identity column
- actions for long forms
- persistent task navigation

Do not make too many regions sticky simultaneously.
