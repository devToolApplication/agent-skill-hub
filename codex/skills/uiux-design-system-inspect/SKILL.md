# uiux-design-system-inspect

Locate and report existing design-system facts:

- semantic color/theme tokens;
- typography scale;
- spacing/radius/elevation tokens;
- breakpoints/density conventions;
- reusable button/input/dialog/drawer/table/list/menu primitives;
- loading/empty/error/status patterns;
- focus/keyboard/accessibility primitives;
- existing responsive design patterns.

Do not decide a new token system, choose FE implementation architecture, or edit files.

Return facts/evidence only. Read `references/preflight.md`, `references/design-system-inventory.md`, `references/self-check.md`.
