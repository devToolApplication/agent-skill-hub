# FE Code Edit Self-Guard

Before PASS verify:

- all changed files are allowed;
- every change maps to a TaskSpec instruction;
- every referenced UIUX requirement ID is preserved;
- no new UX decision was invented;
- no second state/query/i18n/theme mechanism was introduced;
- no hard-coded visible text/raw theme value bypass was introduced against policy;
- accessibility semantics were not weakened;
- verification/self-check evidence is recorded.
