# Navigation Rules

## User Language

Navigation labels should match the user's mental model, not service/class/database names.

Prefer:
Users
Transactions
Reports
Settings

Avoid:
USR_CORE
SYS_MGMT
CFG_ENGINE

## Depth

Prefer shallow navigation.

Common:
1–2 levels

Third level requires justification.

## Sidebar

Good for:
- enterprise apps
- many persistent modules
- desktop productivity

Group related items using meaningful section labels.

## Top Navigation

Good for:
- few major product areas
- consumer/product websites
- broad top-level switching

## Bottom Navigation

Good for mobile when there are roughly 3–5 high-frequency destinations.

## Tabs

Use for peer sections of the same context.

Do not use tabs as a fake stepper.

## Breadcrumb

Use when hierarchy is deep enough that location/context is otherwise unclear.

## Active State

Current location must be obvious through more than a tiny color shift.

Use some combination of:
- background
- indicator
- font weight
- icon/text state
