# UIUX Spec Verification Method

1. Read exact uiux-spec-v1.
2. Restrict to requested requirement IDs.
3. Inspect exact implementation evidence supplied/scoped.
4. Map evidence to each requirement.
5. Mark SATISFIED only when evidence supports it.
6. Mark VIOLATED only with concrete contradictory evidence.
7. Otherwise mark NOT_VERIFIABLE.

Do not convert uncertainty into PASS.
