# Release Scope Control

Phân biệt MVP vs phase 2, in-scope/out-of-scope, kiểm soát scope creep.

## Khi nào dùng
- Feature lớn hoặc nhiều request phát sinh
- Planning release/MVP
- Requirement có nhiều nice-to-have

## Workflow
1. Xác định business outcome tối thiểu.
2. Liệt kê capabilities.
3. Phân loại Must/Should/Could/Won't.
4. Define release boundary.
5. Ghi assumptions/dependencies.

## Output
| Capability | Priority | Release | Reason |
|---|---|---|---|

## Rules
- MVP phải deliver end-to-end value
- Nice-to-have đưa phase 2
- Scope addition phải đánh giá impact
- Out-of-scope ghi rõ

## Checklist
- [ ] MVP end-to-end usable
- [ ] Out-of-scope explicit
- [ ] Dependencies identified
- [ ] Deferred items retained
