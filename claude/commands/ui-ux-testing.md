# UI/UX Testing

Test layout, responsive, accessibility, interaction states.

## Khi nào dùng
- Test màn hình UI sau dev
- Review responsive behavior
- Check UX states: loading/empty/error/success
- Validate interactions and visual hierarchy

## Coverage
- Layout desktop/tablet/mobile
- Primary/secondary action hierarchy
- Form validation and error messages
- Loading skeleton/spinner
- Empty state
- Error state and retry
- Keyboard navigation
- Focus states
- Contrast/readability

## Checklist
- [ ] One primary focus in first viewport
- [ ] No horizontal scroll on mobile
- [ ] Touch targets >= 44px
- [ ] Loading/empty/error states present
- [ ] Form validation clear
- [ ] Keyboard navigation works
- [ ] Focus visible
- [ ] Text readable and contrast OK
