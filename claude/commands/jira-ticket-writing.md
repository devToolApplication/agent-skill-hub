# Jira Ticket Writing

Viết Jira ticket rõ, testable, đủ context cho Dev/Test.

## Khi nào dùng
- Tạo Epic/Story/Task/Bug
- Convert functional spec thành backlog

## Story Template
```md
## Summary
Short outcome-oriented title

## Context
Why this is needed

## User Story
As a ..., I want ..., so that ...

## Scope
In scope / out of scope

## Acceptance Criteria
Given/When/Then

## Dependencies
...

## References
Design/API/docs
```

## Bug Template
```md
## Environment
## Preconditions
## Steps to reproduce
## Actual result
## Expected result
## Evidence
## Severity / impact
```

## Checklist
- [ ] Title outcome-oriented
- [ ] AC testable
- [ ] Dependencies listed
- [ ] Scope boundary clear
