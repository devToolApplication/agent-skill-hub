# UI/UX Requirement

Đặc tả màn hình, form, table, interaction và UI states để FE/Test triển khai thống nhất.

## Khi nào dùng
- Feature có UI mới hoặc thay đổi UX
- Cần handoff BA → Dev FE/Test
- Làm rõ hành vi màn hình

## Output
- Screen purpose
- Primary user goal
- Components and actions
- Field definitions and validation
- Loading/empty/error/success states
- Responsive behavior
- Accessibility expectations

## Rules
- Một primary focus trong first viewport
- Phân cấp primary/secondary/advanced actions
- Mọi form có validation message
- Mọi async action có loading, success, error states

## Checklist
- [ ] Happy path rõ
- [ ] Empty/loading/error states rõ
- [ ] Mobile behavior rõ
- [ ] Keyboard/accessibility expectations rõ
