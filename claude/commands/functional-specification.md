# Functional Specification

Viết functional design doc rõ để Dev/QA implement.

## Khi nào dùng
- Feature mới cần tài liệu BA
- Chuyển requirement sang Dev/Test
- Làm rõ UI/API/data behavior

## Template
```md
# Functional Specification: [Feature]

## Input
Original request/context

## Objective
Business goal

## Users & Permissions
Actors, roles, access rules

## Functional Flow
Step-by-step behavior

## Business Rules
Rule list

## UI Requirements
Screens/states/actions

## API/Data Requirements
Fields, validations, errors

## Acceptance Criteria
Given/When/Then

## Edge Cases
...

## Out of Scope
...

## Next Role
Architect/Dev/Test action
```

## Checklist
- [ ] Dev can implement without guessing
- [ ] QA can test from this doc
- [ ] Open questions explicit
